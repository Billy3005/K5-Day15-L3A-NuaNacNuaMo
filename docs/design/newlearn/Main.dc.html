Cú pháp SELECT & FROM

Mục tiêu bài: Hiểu và viết được câu SELECT cơ bản để lấy dữ liệu từ 1 bảng.

{{sec.text}}

Ví dụ

Giả sử có bảng students với các cột id, name, age:

SELECT id, name FROM students;

Bài tập

Viết 3 câu SELECT để lấy dữ liệu:

  1. Chỉ lấy 1 cột (ví dụ: SELECT name FROM students;)
  2. Lấy 2 cột (ví dụ: SELECT id, age FROM students;)
  3. Lấy cột cụ thể thay vì * (không dùng SELECT *)
